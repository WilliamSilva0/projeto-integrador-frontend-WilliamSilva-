# Burguer Pro

Site de cardápio digital para a hamburgueria fictícia Burguer Pro. 
O projeto apresenta os itens do cardápio, 
seus preços, e um formulário de reserva de mesa para os clientes. 
Desenvolvido como Projeto Integrador da disciplina de Desenvolvimento Front-end.

**Revisão** feita por Pedro Cocentino no dia 27/08/2026: William Silva cumpriu com todos os requisitos de forma excelente. Além de cumprir tudo até a aula 4, ele adicionou css, que deixou a aplicação mais bonita e agradável. 10/10

**Revisão**
Revisado Por Mateus Aragão França
O projeto está bem estruturado e organizado, apresentando uma boa aplicação dos conteúdos estudados. O HTML utiliza elementos semânticos, o CSS trabalha bem a estilização e o layout, e o JavaScript adiciona funcionalidades ao cardápio. Também foram incluídos formulário de reserva e recursos multimídia.
Como sugestão de melhoria, seria interessante adicionar um filtro por categoria no cardápio, facilitando a busca pelos produtos, além de mostrar a quantidade de itens encontrados e atualizar esse resultado automaticamente com JavaScript, aplicando os conceitos de DOM e eventos da aula 12.. No geral, um ótimo trabalho, com possibilidades de melhorar ainda mais a interatividade e a experiência do usuário.
