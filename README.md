# Burguer Pro

Site de cardápio digital para a hamburgueria fictícia Burguer Pro. 
O projeto apresenta os itens do cardápio, 
seus preços, e um formulário de reserva de mesa para os clientes. 
Desenvolvido como Projeto Integrador da disciplina de Desenvolvimento Front-end.
